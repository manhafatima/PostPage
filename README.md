## WEB102 Capstone: PostPage 

This is a React-based post application that allows users to create, view, and interact with posts. The app uses Supabase as a backend database to store posts and comments. Users can create posts with titles, text content, and external image URLs, browse posts through a feed, search and sort posts, interact through upvotes and comments, and manage their own posts through editing and deletion.

---

## 🎯 Features 

### ✅ Required Features

- Create posts with a required title, optional text content, and image URL
- Home feed displaying all posts with creation time, title, and upvote count
- Post pages with full content, images, and comments
- Sort and search posts by creation time, upvotes, or title
- Interact with posts by adding comments and upvoting
- Edit posts to update the title, content, and image URL
- Supabase integration for storing and retrieving posts, comments, and upvotes
